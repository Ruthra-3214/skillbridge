# SkillBridge

A beginner-friendly career roadmap website prototype built with HTML, CSS, and vanilla JavaScript.

## Features
- Select Data Scientist, AI/ML Engineer, or Web Developer
- Self-assess skills
- Generate a rule-based skill-gap summary
- View a four-week learning roadmap
- Get a small portfolio project and checklist
- Open free learning resources
- Track weekly and project progress using browser localStorage
- Responsive layout for mobile and desktop

## Run locally
1. Extract the ZIP file.
2. Open the `skillbridge` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Choose a career, select familiar skills, and click **Generate my roadmap**.

No installation, API key, or server is required.

## Important limitations
- This is a front-end demonstration. It does not use a real AI model.
- Recommendations are based on predefined rules and sample career plans.
- Progress is saved only in the current browser on the current device.
- Do not present the readiness percentage as a validated employment prediction.
- To support multiple users and shared progress, add a backend/database later.
